# Python Docstring Helper

Расширение для **Visual Studio Code**: создаёт и обновляет docstring функций Python в стиле Google на основе анализа кода.

**Автор:** `Печерина Кристина Евгеньевна`, группа `М3119`


## Возможности

- Документирует функцию под курсором (`Cmd+option+Shift+D`).
- Документирует все функции файла (через палитру команд).
- Разбирает многострочные заголовки, аннотации типов, значения по умолчанию, `*args`, `**kwargs`.
- Определяет тип параметра по значению по умолчанию, если нет аннотации.
- Пропускает `self` и `cls` у методов.
- Находит `return`, `yield` и `raise`, не учитывая вложенные функции, строки и комментарии.
- Обновляет существующий docstring: добавляет новые параметры, убирает удалённые, сохраняет написанные описания.
- Отменяется одним `Ctrl+Z`; текст-заполнитель меняется в настройке `docstringGenerator.placeholder`.

## Запуск

1. Открыть папку проекта в VS Code (версия 1.75 или новее).
2. Нажать `F5`. Откроется окно Extension Development Host.
3. В новом окне открыть `examples/demo.py`, поставить курсор внутрь функции и нажать `cmd+option+shift+D`.

Сторонние пакеты не нужны. Тесты (нужен Node.js 18 или новее): `npm test`.

## Пример

До:

```python
def add(a: int, b=2):
    return a + b
```

После:

```python
def add(a: int, b=2):
    """TODO: описание функции add.

    Args:
        a (int): TODO.
        b (int): TODO. По умолчанию 2.

    Returns:
        TODO.
    """
    return a + b
```

## Ограничения

- Функции, записанные в одну строку (`def f(): pass`), пропускаются.
- Разделы распознаются только в стиле Google. Текст в стилях NumPy и reST сохраняется как описание.
- В разделе `Args` сохраняются записи вида `имя: описание`; прочий текст перед первой записью удаляется.
- Обычный текст, стоящий после разделов, переносится в описание.
